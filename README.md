# FrameFind

FrameFind is a visual-discovery app where people will be able to search a topic and browse matching images in a responsive gallery. I chose a warm paper background with deep teal accents to give the interface a calm, editorial feel that is distinct from the PixelPulse reference. The large, question-led hero makes the next action obvious as soon as someone lands on the page. I also added quick-pick topic chips and a clear empty state so the page feels useful before a search has been made.

## Part 1

This version contains the HTML structure and responsive CSS only. The results grid is intentionally empty; image fetching and rendering will be implemented in Part 2.
